# Studio 插件分发

Studio 当前不预装业务插件，`builtin/packages.json` 保持为空。
OMP 由独立仓库维护，在插件中心通过仓库地址或本地目录安装、启用和升级；
Studio 不引用其 npm 包、不复制其源码，也不在启动时安装或更新它。

历史版本已安装的插件继续使用自己的安装快照和稳定的 `ctx.paths.dataDir`。
移除内置分发不会卸载已有插件，也不会删除配置、引擎或会话。
设置、模型配置、原生引擎和文件格式由插件负责，scoped 模型凭证和运行上下文由 Studio 注入。

通用内置目录基础设施保留供目录解析和旧安装记录使用；当前没有产品插件条目。
测试夹具只放在 `tests/fixtures/plugins`，不加入正式分发目录。
配置和用户操作见 [插件文档](../docs/plugins.md)。
