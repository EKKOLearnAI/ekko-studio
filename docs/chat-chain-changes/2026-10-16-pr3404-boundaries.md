# PR #3404 follow-up boundaries

- Protocol filtering recognizes fenced code inside list and quote containers,
  including their continuation indentation. Literal XML remains intact in both
  streaming persistence and Markdown rendering; structural protocol following
  the code is still removed. Prefix tracking is bounded independently of line
  length.
- Hermes queue insertion requests and recalls are serialized per session.
  Removing the last queued message and inserting another during a slow recall
  cannot let the old recall clear the new boundary. Late acknowledgement cleanup
  runs within the same ordering, while other sessions remain independent.
- Workspace snapshots suppress attribution when concurrent sessions scan equal
  or overlapping parent/child roots. Independent sibling directories still
  receive change summaries. Paths on separate Windows volumes do not overlap.

Regression coverage lives in `tool-call-markup.test.ts`,
`run-chat-bridge-delta.test.ts`, `run-chat-queued-item.test.ts`,
`workspace-diff-tracker.test.ts`, and `chat-protocol-text.spec.ts`.
