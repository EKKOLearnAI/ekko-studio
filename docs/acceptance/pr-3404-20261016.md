## Additional defect found: profile deletion timeout

On the installed Linux instance, deleting a newly created fixture profile
returned HTTP 500 because the CLI was killed after 10 seconds. Running the same
CLI cleanup with enough time completed successfully in **21.683 seconds**, and
removed the profile and its wrapper.

The follow-up raises only `deleteProfile`'s bounded subprocess timeout to 120
seconds. Its regression uses a real 11-second subprocess: the old implementation
fails, the corrected implementation succeeds, and nonzero CLI exits still report
failure. The added test is POSIX-only; no new Windows profile-deletion acceptance
is claimed.

The local follow-up validation passed **40/40** related tests, the repository
harness and the full build. A separately built instance also created/deleted a
real Hermes profile with HTTP 200 and verified its disappearance. That particular
successful deletion took 1.283 seconds; the slow-path evidence is the distinct
11-second regression and 21.683-second observed cleanup.
